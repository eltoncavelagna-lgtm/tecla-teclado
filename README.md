# Tecla — aulas interativas de teclado

Aplicativo estático em português para aprender as teclas, praticar sequências e tocar melodias progressivas.

## Recursos

- Seis aulas guiadas com demonstração do computador antes da repetição do aluno.
- Teclado interativo com nomes das notas.
- Prática por teclado musical físico via MIDI ou microfone do dispositivo.
- Progresso salvo localmente no navegador.

## Publicação

O site roda como conteúdo estático. Abra `index.html` em um navegador ou publique a pasta pela funcionalidade GitHub Pages.

As aulas atuais são interativas e animadas; ainda não incluem gravações de vídeo. O progresso fica neste navegador e não sincroniza entre dispositivos. A entrada por microfone depende da permissão do navegador e funciona melhor com uma nota por vez.
